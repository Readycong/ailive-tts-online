# 招呼设置功能说明

## 功能概述
在ModelScreen中实现了"招呼设置"点击事件功能，用户可以通过该功能配置直播时的自动招呼参数。

## 功能详情

### 1. 入口位置
- **页面**: ModelScreen (主播模型页面)
- **位置**: "控制参数"区域中的"招呼设置"卡片
- **图标**: 发送图标(Icons.AutoMirrored.Filled.Send)

### 2. 招呼设置页面
点击"招呼设置"后进入专门的设置页面，包含以下表单项：

#### 2.1 主动招呼
- **组件**: Switch开关
- **默认值**: 开启(true)
- **功能**: 控制是否对沉默与在线用户进行随机点名问候
- **提示文案**: "开启后会对沉默与在线用户进行随机点名问候"

#### 2.2 最大在线人数
- **组件**: 整数输入框
- **默认值**: 20人
- **限制**: 必须为自然数，不超过100
- **功能**: 设置在线人数上限，超过后不进行点名问候
- **提示文案**: "在线人数超过后不进行点名问候"

#### 2.3 响应延迟
- **组件**: 整数输入框
- **默认值**: 5秒
- **限制**: 0-20秒，0为不延迟
- **单位**: 秒
- **功能**: 设置点名问候的延迟时间
- **提示文案**: "0为不延迟"

### 3. 页面布局
- **顶部栏**: 
  - 标题: "招呼设置"
  - 左侧: 返回按钮
  - 右侧: 保存按钮
- **表单布局**: 垂直排列的卡片式表单
- **提示显示**: 每个表单项下方以小字显示提示信息

### 4. 数据验证
- **最大在线人数**: 必须输入0-100之间的整数
- **响应延迟**: 必须输入0-20之间的整数
- **错误提示**: 输入不合法时显示具体错误信息

### 5. 保存功能
点击右上角"保存"按钮时：
1. 验证所有输入的合法性
2. 验证通过后保存设置
3. 返回上一级页面

## 技术实现
- **导航**: 使用NavigationState进行页面跳转
- **状态管理**: 使用remember保存表单状态
- **UI组件**: Material3组件库
- **输入验证**: 实时验证用户输入
- **用户体验**: 卡片式布局，清晰的分组和提示

## 使用流程
1. 进入ModelScreen页面
2. 点击"控制参数"区域的"招呼设置"
3. 在招呼设置页面配置各项参数
4. 点击右上角"保存"按钮保存设置
5. 自动返回ModelScreen页面
